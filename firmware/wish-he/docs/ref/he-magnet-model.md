# HE 스위치 자속-변위 모델 및 LUT 설계 근거

Hall effect 키보드 펌웨어의 거리 환산(LUT) 설계 근거를 정리한 문서.
ADC 값을 키 눌림 거리(mm)로 변환하는 부분의 물리적 배경과, 그로부터
도출되는 캘리브레이션 구조를 다룬다.

- 작성: 2026-08-16
- 관련 스크립트: `he_magnet_fit.py`
- 그림: `he-magnet-model.png`

---

## 1. 요약

| 항목 | 결론 |
|---|---|
| 제조사 데이터시트에 곡선이 있나 | **없다.** 2점(초기/바닥 자속)만 공개 |
| 2점으로 곡선을 복원할 수 있나 | **가능하다.** 물리 모델에 미지수 2개를 풀면 결정됨 |
| 자석 형상을 몰라도 되나 | **된다.** 양 끝점 고정 시 형상 가정의 영향 < 0.1 % |
| ADC → 거리 선형 매핑 | **불가.** 최대 0.95 mm 오차, 그것도 액추에이션 구간에서 |
| 키마다 LUT가 필요한가 | **아니다.** 공용 LUT 1개 + 키별 끝점 2개면 충분 |
| 지그 실측은 | 전수 측정 불필요. 모델 검증용 1회면 됨 |

핵심 설계 결론:

> **정규화 좌표 `u = (adc - adc_rest) / (adc_bottom - adc_rest)` 에서
> 곡선 모양은 개체차와 무관하다.** 따라서 플래시에는 `u → 거리` LUT 하나만
> 두고, 키별로는 `adc_rest`, `adc_bottom` 두 개의 uint16만 저장하면 된다.

## 2. 제조사가 주는 정보

스위치 제조사는 전체 B–z 곡선을 공개하지 않는다. 공개되는 것은 2점뿐이다.

| 스위치 | 초기 자속 | 바닥 자속 | 총 트래블 | 비 |
|---|---:|---:|---:|---:|
| Gateron Magnetic Jade | 120 ± 15 Gs | 700 ± 80 Gs | 3.5 ± 0.2 mm | 5.83 |
| Gateron Magnetic Jade Pro | 120 ± 8 Gs | 700 ± 30 Gs | 3.5 ± 0.1 mm | 5.83 |
| Gateron KS-20 / Dual-Rail | 102 ± 15 Gs | 905 ± 80 Gs | 4.1 ± 0.2 mm | 8.87 |
| Gateron KS-37B Magnetic Fox | 120 ± 15 Gs | 800 ± 80 Gs | 4.0 mm | 6.67 |

### 읽을 때 주의할 점

**1. 이 값은 자석 표면 기준이 아니다.** 최신 스펙에는
`120±8GS (PCB 1.2mm)` 처럼 PCB 두께가 병기된다. 즉 **센서 감지면까지의
갭을 포함한 값**이다. PCB 두께가 다르면 그대로 쓸 수 없고, 두께 차이만큼
갭 항을 보정해야 한다.

**2. 극성을 확인해야 한다.** Gateron KS-20 계열은 N극이 PCB를 향한다.
센서의 극성 응답 방향과 맞지 않으면 부호가 뒤집힌다.

**3. 공차가 크다.** ±12 % 수준이며 이건 개체차라 모델로 잡을 수 없다.
4절의 정규화가 이 문제를 해결한다.

## 3. 물리 모델과 2점 피팅

### 3.1 지배 방정식

축방향으로 자화된 원통 자석의 축상 자기장:

$$B(z) = \frac{B_r}{2}\left[\frac{z+L}{\sqrt{(z+L)^2+R^2}} - \frac{z}{\sqrt{z^2+R^2}}\right]$$

- $z$ : 자석 면에서 홀 소자 감지면까지 거리 (mm)
- $R$ : 자석 반지름, $L$ : 자화축 방향 길이 (mm)
- $B_r$ : 잔류자속밀도. NdFeB는 N35 ≈ 1.17 T, N52 ≈ 1.45 T가 상한

키가 $d$ 만큼 눌렸을 때 갭은 $z = z_0 + (T - d)$. 여기서 $z_0$는 바닥까지
눌렸을 때의 갭, $T$는 총 트래블.

### 3.2 미지수 2개, 방정식 2개

$$B(z_0) = B_{\text{bottom}}, \qquad B(z_0 + T) = B_{\text{initial}}$$

비를 취하면 $B_r$이 소거되고 $z_0$에 대한 1차원 근찾기가 된다. $z_0$를
구한 뒤 어느 한 식에 대입해 $B_r$을 얻는다.

> **주의 — 흔한 실수.** $z_0$를 임의로 가정하고 $B_r$ 하나만 맞추면 안 된다.
> 그러면 나머지 한 점이 30 % 넘게 어긋난다. 미지수 2개를 **둘 다** 풀어야 한다.

### 3.3 자석 크기가 역산된다

$R$, $L$을 스캔하면서 $B_r \le 1.45$ T 조건을 걸면 대부분의 후보가 탈락한다.

Gateron Jade (120 → 700 Gs, 3.5 mm) 기준:

| 가정 자석 | $z_0$ | 역산 $B_r$ | 판정 |
|---|---:|---:|---|
| Ø2 × 1.5 mm | 3.57 mm | 7.69 T | ✗ 물리적으로 불가능 |
| Ø3 × 2.0 mm | 3.15 mm | 2.45 T | ✗ 불가능 |
| Ø4 × 2.0 mm | 2.74 mm | 1.23 T | ✓ N40급 |
| Ø4 × 2.5 mm | 2.59 mm | 1.01 T | ✓ N35급 |

즉 **2점 스펙만으로 자석 지름의 하한(약 3 mm)이 나온다.**

그리고 유효 갭이 $z_0 \approx 2.6\text{–}2.8$ mm로 나오는데, 이건 홀 센서가
**PCB 밑면에 실장**되어 있음을 뜻한다. 스펙에 PCB 두께가 병기되는 이유가
이것으로 설명된다. 자체 PCB 설계 시 센서 실장면을 결정할 때 참고할 것.

## 4. 형상 가정의 영향은 무시할 수 있다

양 끝점을 고정하고 나면 곡선 **모양**은 자석 형상 가정에 거의 무관하다.

| 가정 | 중간 구간 최대 편차 | 거리 환산 |
|---|---:|---:|
| Ø4 × 2.0 vs Ø4 × 2.5 mm | 0.1 % | ~2 µm |

물리 형태(축상 감쇠)가 이미 모양을 결정해버리기 때문이다. **모델로 LUT를
생성해도 된다**는 근거가 여기에 있다.

### 4.1 정규화 좌표에서의 불변성

$$u = \frac{\text{adc} - \text{adc}_{\text{rest}}}{\text{adc}_{\text{bottom}} - \text{adc}_{\text{rest}}}$$

이 좌표에서 곡선 $d(u)$가 개체차에 얼마나 둔감한지 측정한 결과:

| 변동 요인 | 범위 | $u$ 최대 편차 | 거리 오차 |
|---|---|---:|---:|
| 자화 세기 $B_r$ | ±12 % | **0.0000 %** | **0 µm** |
| 센서 오프셋 전압 | 임의 | **0.0000 %** | **0 µm** |
| 안착 높이 $z_0$ | ±0.2 mm | 0.62 % | 26 µm |

$B_r$과 오프셋이 정확히 0인 이유는 수학적이다. ADC 읽기가 자속의
아핀 변환 $\text{adc} = a + b\,B$ 라면 $u$는 $a$, $b$에 대해 불변이다.
자화 세기는 $b$에, 센서 quiescent 오프셋은 $a$에 흡수된다.

**따라서 스위치 공차 ±12 %는 키별 끝점 캘리브레이션만으로 완전히 소거된다.**
남는 건 안착 높이 편차뿐이고, 이것도 26 µm 수준이라 Rapid Trigger 감도
(보통 0.1 mm 이상)보다 한 자릿수 작다.

## 5. 그래프

![HE magnet model](he-magnet-model.png)

1. **Forward** $B(d)$ — 실제 물리. 바닥 근처에서 급격히 상승
2. **Inverse** $d(B)$ — 펌웨어가 실제로 필요한 방향. 점선이 선형 가정
3. **Normalised** $d(u)$ — 안착 높이 ±0.2 mm 세 곡선이 겹침

### 5.1 선형 매핑을 쓰면 안 되는 이유

| 눌린 거리 (mm) | 실제 자속 (Gs) | 선형 가정 (Gs) |
|---:|---:|---:|
| 0.00 | 120 | 120 |
| 0.50 | 147 | 203 |
| 1.00 | 182 | 286 |
| 1.50 | 230 | 369 |
| **2.00** | **295** | **451** |
| 2.50 | 385 | 534 |
| 3.00 | 513 | 617 |
| 3.50 | 700 | 700 |

ADC를 선형으로 거리에 매핑하면 **최대 0.95 mm** 틀리며, 오차 최대점이
트래블 2.1 mm 부근이다. 즉 액추에이션 포인트를 잡는 바로 그 구간이다.

Rapid Trigger는 이 거리값의 차분 위에서 동작하므로 오차가 더 증폭된다.
곡선의 국소 기울기가 구간에 따라 3배 이상 변하기 때문에, 선형 매핑
상태에서는 같은 물리적 되돌림 거리가 눌림 깊이에 따라 다른 값으로
읽힌다. LUT가 선택이 아니라 필수인 이유.

## 6. 펌웨어 적용

### 6.1 LUT 인덱싱 — 균일 거리로 잡을 것

$u$를 균일 분할해 LUT를 만들면 안 된다. 곡선이 가파른 구간에서 해상도가
무너진다. 실제로 $u$ 균일 분할 시 첫 구간(`u` 0 → 0.0625)이 거리로
**0.64 mm**를 덮어버린다.

**거리를 균일 분할하고 $u$를 저장한 뒤, 조회 시 이진 탐색 + 선형 보간**
하는 것이 옳다. 이러면 거리 해상도가 전 구간 일정하다.

### 6.2 생성된 테이블 (Jade, 3.5 mm, 33 entry)

```c
/* travel 3.5 mm, 33 entries, uniform 109.4 um steps
 * index i  ->  travel = i * 0.109375 mm
 * value    -> normalised u in q15
 */
static const uint16_t he_curve_q15[33] = {
        0,   300,   617,   954,  1311,  1689,  2091,  2518,
     2973,  3457,  3972,  4522,  5109,  5737,  6407,  7125,
     7894,  8719,  9605, 10557, 11581, 12684, 13873, 15155,
    16541, 18040, 19662, 21421, 23328, 25399, 27651, 30100,
    32767,
};
```

다른 스위치는 `he_magnet_fit.py`로 재생성:

```
python he_magnet_fit.py --initial 102 --bottom 905 --travel 4.1 -n 65
```

### 6.3 조회 경로

```
adc  ──▶ oversample ──▶ median ──▶ adaptive EMA
                                        │
                                        ▼
                        u = (adc - rest) / (bottom - rest)   [q15]
                                        │
                                        ▼
                        binary search in he_curve_q15
                                        │
                                        ▼
                        linear interpolate ──▶ travel [um]
                                        │
                                        ▼
                        actuation + hysteresis / Rapid Trigger
```

키별 저장 항목은 `adc_rest`, `adc_bottom` 두 개(uint16)뿐이다.
104키 기준 416 B.

### 6.4 캘리브레이션 절차 (지그 불필요)

1. 전원 인가 후 안정화 대기 (온도 항목 참조)
2. rest 상태 ADC 다중 샘플 평균 → `adc_rest`
3. 사용자에게 전 키 1회 완전 압하 요구 → 최대값 → `adc_bottom`
4. 끝. 곡선은 공용 LUT가 담당

`adc_bottom - adc_rest`가 예상 범위를 크게 벗어나면 스위치 미장착 또는
자석 이탈로 판정하고 해당 키를 비활성화할 것.

## 7. 모델의 한계

정규화가 흡수하지 못하는 항목들.

**측면 오프셋 (slide-by).** 스템 흔들림이나 센서 실장 편차로 자석이 축에서
벗어나면 축상 공식이 깨진다. Allegro 문서가 head-on과 slide-by를 별도로
다루는 이유이며, 자석 제조사도 slide-by 곡선은 제공하지 않는다 — 에어갭
선택에 따라 곡선이 무한히 갈라지기 때문. 이건 실측 아니면 확인 불가.

**각형 자석.** 원통이 아니면 근거리에서 형태가 달라진다. 다만 $z_0$가
자석 지름과 비슷한 거리(2.7 mm vs 4 mm)라 차이는 작을 것으로 본다.

**온도.** NdFeB $B_r$ 온도계수 약 −0.12 %/°C. 25 °C 변화면 3 % 이동.
곡선 **모양**이 아니라 스케일만 움직이므로 4.1절에 의해 정규화가 흡수한다.
단 `adc_rest`가 같이 움직여야 하므로, adaptive EMA 베이스라인이 rest 값을
추종하도록 되어 있어야 한다. 냉간 상태 직후 캘리브레이션은 피할 것.

**센서 비선형.** 위 모델은 홀 센서 출력이 자속에 선형이라 가정한다.
고자속 영역에서 포화가 시작되면 어긋난다. 바닥 자속 700–905 Gs
(70–90 mT)는 대부분의 선형 홀 IC 범위 내이지만, 선택한 센서의
데이터시트 선형 구간을 확인할 것.

## 8. 검증 계획

모델을 신뢰하기 전 1회 실측 권장. 전수 측정은 불필요.

1. 마이크로미터 Z 스테이지 또는 피더 게이지 심으로 자석-센서 거리 제어
2. **TEAG 기준으로 측정** — 자석 표면부터가 아니라 센서 감지면 기준
3. 지그 재질에서 자성체 배제
4. 측정 (거리, ADC) 쌍을 정규화해 `he_curve_q15`와 비교
5. 편차가 전 구간 1 % 이내면 모델 채택

센서 데이터시트의 mV/mT 감도를 쓰면 ADC 코드를 mT로 역산해 절대값
검증도 가능하다.
